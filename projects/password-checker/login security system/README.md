# Secure Login System

## Description
A secure login system written in Python.

## Features

- User registration
- Secure login
- Password hashing (PBKDF2-HMAC)
- Random salt generation
- Password masking
- JSON account storage
- Login logging
- Multiple login attempts

## Security concepts learned

- Password hashing
- Salt
- PBKDF2
- HMAC compare_digest
- Secure password storage
- Logging

## Technologies

- Python 3
- hashlib
- hmac
- json
- logging
- os

## Future improvements

- Account lockout timer
- Password reset
- Multi-factor authentication
- Database support
